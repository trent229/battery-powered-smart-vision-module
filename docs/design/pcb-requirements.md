# PCB Requirements

## Project

Battery-Powered Smart Vision Module

Version 1.0

---

# Purpose

Design a compact printed circuit board that powers and supports the XIAO ESP32S3 Sense while providing battery charging, protection, expansion, and status indication.

---

# Required Features

- USB-C charging
- LiPo battery connector
- Battery charging circuit
- Battery protection
- Power switch
- Status LED
- XIAO ESP32S3 mounting headers
- Expansion headers
- Test points

---

# Mechanical Requirements

Maximum PCB Size

70 mm x 50 mm

Mounting

4 mounting holes

Corner Radius

3 mm

---

# Electrical Requirements

Input

USB-C 5V

Battery

3.7V LiPo

System Voltage

3.3V

Maximum Current

1A
